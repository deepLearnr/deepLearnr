# Kalpesh Waghmare

**Applied AI · GenAI applications · Machine learning**

I work on practical AI projects, from retrieval-based applications and backend systems to deep-learning experiments and exploratory quantum ML.

My current focus is understanding how these systems work end to end: how data is prepared, how retrieval is grounded in source material, how models are evaluated, and how the surrounding software is tested and maintained.

## Selected work

### [RBI Saathi — Regulatory Intelligence & Learning Prototype](https://github.com/deepLearnr/rbi-capstone)

A group capstone exploring RBI regulatory documents through retrieval-augmented question answering and a learning-oriented web application.

- My contributions: backend development, database persistence, document and chunk APIs, source metadata, and RAG-related integration.
- Stack: FastAPI, PostgreSQL, SQLAlchemy, Alembic, React, and Vite.
- [Live demo](https://rbi-capstone.kalpeshw070.workers.dev/)

### [Quantum Weather Prediction](https://github.com/deepLearnr/quantum-weather-prediction)

An ongoing project exploring quantum-computing approaches within a weather-prediction workflow. Current work includes studying the methods, structuring the codebase, and investigating simulation and compute constraints. Results will be documented as experiments are implemented and evaluated.

### [NSDC AI Assistant](https://github.com/deepLearnr/nsdc-ai-assistant)

A forked FastAPI assistant for NSDC and Skill India information, using a local knowledge base, retrieval, and an external LLM provider. See the repository history for the changes in this fork.

- **GenAI:** Retrieval-augmented generation, document ingestion, source-grounded answers

## Current direction

I'm focused on practical GenAI development while building toward deeper ML engineering. That means not only getting a system to run, but understanding its data flow, investigating failure cases, testing behavior, and being precise about what its results actually demonstrate.
